# ProyectoBolsaEmpleo

Proyecto 1 de Programación 4.

## Login de desarrollo

La aplicación ahora crea usuarios de prueba al arrancar si no existen en la base de datos `bolsa_empleo`:

- Empresa: `empresa@demo.com` / `empresa123`
- Oferente: `oferente@demo.com` / `oferente123`
- Administrador: `admin` / `admin123`

## Ejecutar

```powershell
.\mvnw.cmd spring-boot:run
```

Luego abre `http://localhost:8080/login`.
